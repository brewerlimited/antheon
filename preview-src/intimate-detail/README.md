# Intimate Detail interactive homepage snapshot

This isolated preview preserves the original homepage components, local assets, precompiled Tailwind styles, fonts, and motion. Framework image/navigation adapters keep it standalone. The Antheon shared preview guard limits navigation and submission.

To rebuild after editing the copied source, run `npm install` in this directory, then `npm run build`. The generated files go to `public/previews/intimate-detail/`. Existing installations can alternatively provide `PREVIEW_NODE_MODULES=/path/to/node_modules` to the root build script.

The original source site is unchanged. Only this copied snapshot is built and displayed by Antheon.
